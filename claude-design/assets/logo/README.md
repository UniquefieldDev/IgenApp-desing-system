# Igen logó

Szókép (`igen-logo-*.svg`), jel (`igen-mark-*.svg`, csak a két pötty), egyszínű változat (`igen-logo-mono.svg`, `currentColor`), app-ikon és a teljes logóterv PDF-ben. Világos háttérre a `-light`, sötétre a `-dark` fájl; a jel önmagában app-ikonhoz és favicon-hoz. Védőzóna: egy pötty átmérője minden oldalon. Nem színezzük át, nincs árnyék, nincs üveghatás.
