# Menu

Lebegő, liquid glass menü a fejléc ritkán használt pontjaihoz: fiók, partner meghívása, előfizetés, kijelentkezés. Csak lebegő rétegként jelenik meg (legördülő vagy felugró), az oldal tartalmába nem ágyazzuk.

- A fogyasztó adja: `items` (`{label, hint?, onSelect}`; a `'-'` elválasztó), opcionálisan `label` a képernyőolvasónak, valamint a pozicionálást és a nyitás/zárás állapotát.
- Egy menüben legfeljebb 6–7 pont legyen. A romboló művelet (kijelentkezés, törlés) kerüljön az utolsó helyre, elválasztó után.
