# Logo

Az Igen „Két pötty” logója: az i pöttye két egymás felé dőlő kör (`rose`, `lagoon`), a metszetük a betű színe. A színeket a tokenekből veszi, így sötét témában magától a világos változatra vált.

- A fogyasztó adja: `height` (px, alapból 28), opcionálisan `variant="mark"` a két pötty önmagában (app ikon, favicon, szűk hely).
- Legkisebb méret: szókép 20px magas, jel 16px. Körülötte legalább egy pötty átmérőjének megfelelő üres hely maradjon.
- Ne színezzük át, ne tegyük rá árnyékot vagy üveghatást. Egyszínű és kifordított változat: az „Igen logó” PDF-ben.
