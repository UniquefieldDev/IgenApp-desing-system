# DotList

Felsorolás leíró oldalakon (landing, csomagok, súgó): a pont helyén a logó kis, összeért pöttypárja.

- A fogyasztó adja: `items` (rövid mondatok) vagy `children`.
- Csak leíró, márkás szövegben. Adatlistára (vendégek, teendők, szolgáltatók) a `List` való; űrlapban és a menetrendben nincs DotList.
- Egy listában 3–6 elem.
